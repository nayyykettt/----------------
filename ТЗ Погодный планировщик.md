## Назначение и окружение

Локальное веб-приложение для одного пользователя: календарь, в который загружается жёсткое расписание, а гибкие задачи (тренировка, прогулка, магазин, учёба) планировщик расставляет в лучшие слоты недели с учётом погоды, сна и профилей активности.

**Термины**

| Термин | Значение |
| --- | --- |
| Жёсткое событие | Событие из .ics или созданное вручную как обычное событие. Приоритет 0, планировщик его не двигает. |
| Шаблон | Набор правил для типа задачи: длительность, буферы, окна, погода, приоритет. Есть предустановленные, можно создавать свои. |
| Гибкая задача | Один экземпляр шаблона = одно событие. Три тренировки = три задачи. |
| Слот | Конкретный интервал времени, куда можно поставить задачу вместе с буферами. |
| Буфер | Время до и после задачи (дорога, душ). Тоже не должно пересекаться с другими событиями. |
| Профиль активности | Тип (физическая, умственная, рутина) с настраиваемыми окнами времени. |
| Горизонт прогноза | Период, на который доступен почасовой прогноз (обычно около 7 дней). |

**Окружение и стек**

- Стек выбирает Claude Code; требования: запуск локально одной командой, без авторизации, один пользователь.
- Данные (события, шаблоны, задачи, настройки) хранятся локально и сохраняются между запусками (например, SQLite).
- Погода: Open-Meteo — бесплатный, без ключа, почасовой прогноз (температура, вероятность осадков, тип осадков, облачность, ветер). Поиск города по всему миру — через геокодинг Open-Meteo.
- Часовой пояс приложения = часовой пояс выбранного города.
- Язык интерфейса — русский. Температура в °C, ветер в м/с.

## Календарь, повторы и импорт .ics

Календарь ведёт себя как Google Calendar: виды «День», «Неделя», «Месяц», создание, редактирование, удаление и перетаскивание событий.

**Повторяющиеся события**

- Интервал: каждые N дней, недель или месяцев (1, 2, 3 дня; 1, 2, 3 недели; месяц и т. д.).
- Для недельных повторов — выбор конкретных дней недели (пн/ср/пт).
- Дата окончания повтора или «без окончания».
- При изменении или удалении: «только это событие», «это и последующие», «вся серия».

**Импорт .ics**

- Разовая загрузка файла через кнопку в верхней панели. Синхронизации по ссылке нет.
- Поддержать RRULE, EXDATE и разовые события из файла.
- Все импортированные события получают приоритет 0.
- Повторный импорт совмещает расписания. Если события из нового и старого импорта пересекаются по времени, остаётся событие из нового файла.
- Если вы вручную правили импортированное событие, а новый файл содержит событие на этот же промежуток, побеждает событие из файла.
- Если новые события перекрыли уже поставленные гибкие задачи, эти задачи перепланируются автоматически по правилам автопереноса (плашка + подсветка).

## Шаблоны и задачи

Шаблон хранит правила, задача — экземпляр шаблона. Настройка шаблона открывается правым кликом по нему в левой панели.

**Поля шаблона**

| Поле | Описание | Пример для «Тренировки на улице» |
| --- | --- | --- |
| Название | Произвольное | Тренировка на улице |
| Тип активности | Физическая / умственная / рутина (+ свои, необязательно) | Физическая |
| Длительность, мин | Сколько длится сама задача | 60 |
| Буфер до, мин | Время перед задачей | 15 |
| Буфер после, мин | Время после задачи | 30 |
| Окно «с» — «до» | Задача целиком должна уложиться в этот интервал суток | 07:00 — 14:00 |
| Запрещённые дни | Дни недели, в которые задачу ставить нельзя | Вс |
| Учитывать погоду | Вкл/выкл; для домашних задач погода не важна | Вкл |
| Температура, °C | Допустимый диапазон «от» — «до» | +5 — +25 |
| Вероятность осадков, не выше % | Порог | 20 |
| Облачность, не выше % | Порог | 70 |
| Ветер, не сильнее м/с | Порог (порывы или средний — решить при реализации) | 8 |
| Запрещённые явления | Галочки: дождь, снег, гроза, туман | Дождь, снег, гроза |
| Приоритет | 1, 2, 3… — чем больше число, тем ниже приоритет. 0 зарезервирован за жёсткими событиями | 1 |
| Мин. интервал между задачами шаблона, дней | Две задачи одного шаблона не ближе X дней друг к другу | 1 |

**Предустановленные шаблоны:** «Тренировка на улице», «Прогулка», «Поход в магазин», «Учёба». Значения по умолчанию задаёт Claude Code, все поля редактируются.

**Задачи**

- Задача создаётся из шаблона (кнопка или перетаскивание шаблона) и наследует его правила.
- Частота не задаётся: нужно три тренировки — создаются три задачи.
- Пока задача не поставлена в календарь, она висит в левой панели в списке «Не размещены» с причиной (например, «нет прогноза на эти дни»).

## Алгоритм подбора времени и автоперенос

Планировщик предлагает несколько лучших слотов, пользователь кликает по одному, и задача встаёт туда. Планирование идёт только в пределах горизонта прогноза; за его пределами задачи не ставятся.

**Жёсткие ограничения (нарушать нельзя)**

1. Задача вместе с буферами не пересекается ни с одним событием и ни с одной поставленной задачей.
2. Задача не попадает на сон.
3. Задача целиком внутри окна шаблона «с» — «до» и не в запрещённый день недели.
4. Задача начинается позже текущего момента.
5. Слот внутри горизонта прогноза (если шаблон учитывает погоду).

**Мягкие ограничения (влияют на оценку слота)**

- Погода в течение всей задачи: температура в диапазоне, осадки, облачность и ветер не выше порогов, нет запрещённых явлений. Чем ближе температура к середине диапазона, тем выше оценка.
- Попадание в окно профиля активности своего типа.
- Минимальный интервал между задачами одного шаблона.

**Подбор**

1. Перебрать кандидатов с шагом 15 минут в пределах горизонта прогноза.
2. Отсеять по жёстким ограничениям, остальные оценить.
3. Показать 3–5 лучших слотов подсветкой прямо в календаре; клик по слоту ставит задачу.
4. Если ни один слот не выполняет все мягкие правила — показать «лучшие из худших» с пометкой, какие правила нарушены (например, «ветер 10 м/с при пороге 8»).
5. Если не выполняются даже жёсткие ограничения — задача остаётся в «Не размещены» с причиной.

**Приоритеты:** при автоматической расстановке задачи обрабатываются по возрастанию числа приоритета (сначала 1, потом 2…). Жёсткие события (0) не двигаются никогда.

**Автоперенос по погоде**

- Прогноз обновляется при открытии приложения и раз в час, пока оно открыто.
- Если поставленная задача теперь нарушает погодные правила своего шаблона, планировщик сам переносит её в лучший доступный слот позже текущего момента.
- О переносе сообщает плашка («Тренировка перенесена с ср 09:00 на пт 08:00: дождь»), а перенесённое событие подсвечивается в календаре.
- Если подходящего слота нет — задача уходит в «Не размещены», плашка сообщает об этом.

**Ручное перетаскивание**

- Задача, перетащенная мышью вручную, закрепляется (значок замка): автоперенос её не трогает, а при плохом прогнозе показывает только предупреждение.
- Задача, поставленная кликом по предложенному слоту, не закреплена и участвует в автопереносе.
- Закрепление можно снять в меню задачи.
- Всё расписание сохраняется и не сбрасывается при повторном открытии. Обучения на действиях пользователя нет.

## Сон, активность, погода и интерфейс

**Сон**

- Задаётся в настройках отдельно от событий: время отхода ко сну и подъёма.
- Режимы: одно значение для будней и одно для выходных, либо индивидуально на каждый день недели (с кнопкой «скопировать на будни»).
- Сон отображается в календаре затенённой областью; ставить на него задачи нельзя.

**Профили активности**

- Три базовых типа: физическая, умственная, рутина. Для каждого в настройках задаются окна времени (например, физическая 07:00–14:00, умственная 16:00–22:00).
- Свои типы с собственными окнами — желательно, но не обязательно (можно во втором заходе).

**Погодная разметка**

- Каждый час в виде «День» и «Неделя» подкрашен по температуре: градиент от тёмно-синего (холодно) до тёмно-красного (жарко).
- Шкала цветов фиксированная, например от −30 до +35 °C, чтобы один цвет всегда значил одну температуру.
- При наведении на час — подсказка: температура, осадки и их вероятность, облачность, ветер.
- Легенда шкалы видна на экране. За пределами горизонта прогноза часы не подкрашиваются.

**Интерфейс**

- Верхняя панель: переключатель «День / Неделя / Месяц», навигация по датам и кнопка «Сегодня», выбор города (поиск по всему миру), импорт .ics, настройки.
- Левая панель: шаблоны (правый клик — настройка, перетаскивание в календарь — создать задачу и показать лучшие слоты) и список «Не размещены».
- Центр: сетка календаря в стиле Google Calendar с событиями, задачами, сном, погодной подсветкой и подсветкой предложенных слотов.
- Визуально различаются: жёсткие события, гибкие задачи, закреплённые задачи (замок), перенесённые задачи (временная подсветка).

## Этапы, приёмка и границы

**Этапы**

1. Каркас: календарь (день/неделя/месяц), ручные события, повторы, локальное хранение.
2. Импорт .ics с совмещением расписаний.
3. Город, часовой пояс, прогноз и погодная разметка.
4. Настройки сна и профилей активности; шаблоны и задачи, левая панель.
5. Алгоритм подбора: предложение слотов, клик, «лучшие из худших», тесты.
6. Автоперенос по погоде, закрепление, плашки и подсветка.

**Критерии приёмки**

- [ ] Импортирую .ics — события появляются с правильными повторами в часовом поясе города.
- [ ] Импортирую второй .ics с пересекающимся событием — остаётся событие из нового файла.
- [ ] Удаляю одно вхождение серии — остальные на месте.
- [ ] Перетаскиваю «Тренировку» в календарь — подсвечиваются 3–5 слотов, все без пересечений с буферами, сном и запрещёнными днями.
- [ ] Ставлю две тренировки с интервалом 1 день — планировщик не предлагает их в соседние дни (или помечает это как нарушение).
- [ ] При отсутствии подходящих слотов вижу «лучшие из худших» с причинами.
- [ ] Подменяю прогноз на дождь — незакреплённая задача переносится позже текущего момента, есть плашка и подсветка; закреплённая остаётся и получает предупреждение.
- [ ] Закрываю и открываю приложение — всё на месте.

**Вне рамок первой версии:** уведомления, мобильное приложение, несколько пользователей и вход по паролю, обучение на действиях, синхронизация .ics по ссылке, экспорт.

**Допущения аналитика (проверить)**

- Задача, поставленная кликом по предложенному слоту, не закреплена и может автопереноситься; закрепляется только ручное перетаскивание.
- Окно профиля активности — мягкое правило: вне окна задача попадает только в «лучшие из худших».
- Погода проверяется на время самой задачи, без буферов.
- У шаблона есть флаг «Учитывать погоду», чтобы домашние задачи не зависели от прогноза.
- Гибкие задачи, перекрытые новым импортом .ics, автоматически перепланируются.
- Шкала погодной подсветки фиксированная: −30…+35 °C.
